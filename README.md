Тестовое задание 


Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Исправлено
--------------

- **A/B-тест главной страницы.** Главная uchi.ru участвует в A/B-тесте `ab_mainpage_redesign`
  (группы `a` — 80%, `b` и `c` — по 10%). Виджет «Помощь» есть только в группе `a`, поэтому
  примерно в 20% запусков тесты падали. Перед открытием страницы тесты ставят cookie
  `ab_mainpage_redesign=a`.
- **Список популярных статей.** `locator.all()` не ждёт появления элементов: статьи подгружаются
  асинхронно, поэтому возвращался пустой массив и `articles[0].click()` падал с
  `TypeError`. Теперь `getPopularArticles()` возвращает локатор, а тест кликает по `.first()`
  с автоожиданием.
- **Кнопка «Написать нам».** Селектор `[class^=btn]` на странице статьи находит несколько
  элементов (лайк/дизлайк, обёртки кнопок), из-за чего Playwright падал с ошибкой strict mode.
  Используется `[data-test=button_feedback_form]`.
- **Проверка заголовка.** `textContent()` читает текст один раз и без ожидания, поэтому
  в момент проверки там ещё мог быть старый заголовок «База знаний Учи.ру». Теперь
  `getTitle()` возвращает локатор, а проверка идёт через веб-first assertion `toHaveText()`.
- **Обёртка виджета.** Селектор не зависит от служебных классов Stencil-компонента
  (`.sc-dino-typography-h`): `[class^=widget__]:has([data-test=openWidget])`.
- **Cookie-баннер.** На странице два элемента `._UCHI_COOKIE__button` (один из них «фейковый»
  для замеров), клик идёт по кнопке в видимом баннере `._UCHI_COOKIE__wrap.show`.
- Тест `opens` дополнительно проверяет, что до клика виджет скрыт. Без этого тест прошёл бы
  и в случае, когда виджет открыт сразу при загрузке страницы.

Доп тест
-------------------

`closes` — виджет закрывается круглой кнопкой с крестиком, которая появляется
на месте кнопки «Помощь».
